# kino-imdb (privatno)

IMDb ocjene za Kino na Samsung TV-u: GitHub Actions ih svaki dan složi (`build.mjs`, isti kod kao Kino) na granu `data`. TV ih čita ključem samo za čitanje ovog repozitorija. Izvor: IMDb skupovi podataka, osobna nekomercijalna upotreba. Kod se održava u repozitoriju Kina (`scripts/imdb-repo/`).
